# FFball master plan (research and planning, 2026-10-13)

This folder holds the research-backed plan for turning FFball into an integrated fantasy-football
intelligence platform. The platform will:
- forecast players as calibrated distributions;
- simulate the owner's league;
- optimise decisions in wins and title-odds units;
- keep testing whether its recommendations work.

It is **planning only**: no code, models, data or frozen artefacts were changed.
